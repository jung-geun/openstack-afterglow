# VM 생성 위저드 모바일 흐름 개선

## Why

모바일 화면에서 위저드 네비게이션이 콘텐츠보다 먼저 고정되어 본문 시작 영역을 가리고, 좁은 화면에서는 단계별 원형 스텝퍼가 불필요한 세로 공간을 차지한다.

## What Changes

- 모바일에서는 취소·이전·다음 네비게이션을 위저드 콘텐츠 아래에 배치한다.
- 데스크톱에서는 기존 하단 sticky 네비게이션을 유지한다.
- 479px 이하 화면에서는 전체 단계 원형 스텝퍼 대신 단계 수와 진행률을 보여주는 compact progress bar를 표시한다.
- 더 넓은 모바일과 데스크톱에서는 기존 full stepper를 유지한다.

## Out of Scope

- 위저드 단계 순서와 데이터 입력 동작 변경
- 데스크톱 스텝퍼 시각 디자인 변경
