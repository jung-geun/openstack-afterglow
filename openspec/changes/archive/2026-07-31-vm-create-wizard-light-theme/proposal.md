# VM 생성 위저드 화이트 모드 색상 보정

## Why

화이트 모드에서 VM 생성 위저드의 고정 네비게이션과 리뷰 편집 버튼이 다크 모드용 raw 색상을 유지해 주변 콘텐츠와 대비가 어색하고 선택 상태가 불명확하다.

## What Changes

- 위저드 footer 배경과 경계를 디자인 토큰 기반으로 전환한다.
- 이미지/네트워크 선택 칩의 배경과 경계를 테마 토큰으로 전환한다.
- 리뷰 단계 편집 버튼의 기본·hover 색상을 테마 토큰 기반으로 전환한다.
- 위저드 footer의 화이트 모드 토큰 클래스 회귀 테스트를 추가한다.

## Out of Scope

- 위저드의 레이아웃, 단계 순서, 동작 변경
- 인증이 필요한 실제 `/create` 화면의 시각적 QA
