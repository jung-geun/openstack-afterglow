# tutorial-ux-refinement

## 목표

tutorial-guided-tours(2026-07-13 아카이브)로 도입한 튜토리얼을 사용자 피드백에 따라 다듬는다:
mockup 명칭을 제거해 "튜토리얼" 기능으로 정착시키고, 각 페이지에서 시작하며, 실제 화면 상태와
어긋나지 않게 동적으로 동작하도록 개선한다.

## 범위 (프론트엔드 전용)

- 투어 견고화: 오버레이 클릭 무시, 라우트 변경 재앵커, 요소 소실 자동 되감기, 클릭 주도 진행(advanceElement)
- mockup 명칭 제거: URL `?tutorial=on|admin|off`, 배너/에러 문구·픽스처 이름 정리
- 진입 방식 전환: 중앙 런처 모달 제거 → 인스턴스/볼륨/Drover 페이지 헤더의 "튜토리얼" 시작 버튼
- 튜토리얼 모드 화면을 실제 콘솔과 일치: Sidebar 축소 제거, /dashboard 전체 허용, 페이지 픽스처 보강
- VM 위저드 동기화: 전 단계 순차 안내(이미지→플레이버→설정→배포→완료), libraryConsume 베타에 따른
  라이브러리 단계 동적 포함/제외 + 런타임 skipIf, 로딩 대기(readyElement)와 크기 변화 재계산,
  "← 이전" 후진 연동, "취소" 시 투어 종료
- Drover 투어를 필수 필드 순차 안내(이름→OS→마스터 수→에이전트 수→플레이버→생성)로 재구성

## 완료 기준

- frontend vitest 전체 통과, Playwright로 3개 투어 실동작(전진/후진/취소/동적 단계) 확인
