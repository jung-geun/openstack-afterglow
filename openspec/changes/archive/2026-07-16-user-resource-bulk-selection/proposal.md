## Why

사용자 사이드바의 관리형 리소스 목록은 인스턴스를 제외하면 반복 가능한 작업을 한 번에 수행할 일관된 선택 경험이 없다. 프로젝트·목록·현재 조회 결과에 한정된 선택 상태와 접근 가능한 고정 일괄 작업을 제공해 다수 리소스 관리의 반복 조작을 줄인다.

## What Changes

- 기존 인스턴스 선택 UI를 공용 선택 제어, 반응형 selection state, 제한된 동시성의 클라이언트 일괄 실행 계약으로 전환한다.
- Compute 이미지, 스토리지, 파일 스토리지, 컨테이너, 데이터베이스, 오브젝트 스토리지, Key Manager, 네트워크 관리 목록에 해당 리소스가 이미 제공하는 단건 API를 이용한 선택 및 반복 가능한 일괄 작업을 추가한다.
- 선택 불가 리소스는 체크박스를 항상 보이되 비활성화하고, 탭·필터·프로젝트·도메인 변경에서 선택을 안전하게 정리한다.
- 공통 컴포넌트/유틸리티 및 가족별 렌더링 동작을 테스트하고, 튜토리얼 모드 브라우저 검증과 전체 저장소 게이트를 수행한다.

## Capabilities

### New Capabilities

- 사용자 리소스 목록 전반의 행/카드 선택, 전체·부분 선택, 고정 일괄 작업 오버레이
- 선택 가능한 현재 목록에 한정된 bounded client-side bulk mutation 실행

### Modified Capabilities

- 인스턴스와 오브젝트의 기존 선택/일괄 작업 UI를 공용 접근성·상태 계약으로 정리

## Impact

프론트엔드 선택 컴포넌트, UI 디자인 규칙, 다수의 사용자 관리 목록과 해당 테스트가 변경된다. 신규 백엔드 엔드포인트는 만들지 않으며, 인스턴스/오브젝트의 기존 server-side bulk 의미는 유지한다.
