# VM 생성 위저드 고정 네비게이션

## Why

긴 이미지 목록과 설정 단계에서 사용자가 본문을 끝까지 스크롤해야만 다음 작업 버튼을 찾을 수 있어 VM 생성 흐름을 이해하고 진행하기 어렵다. 모바일에서는 이 문제가 더 크게 나타나므로 단계 이동 컨트롤을 항상 보이는 위치에 둔다.

## What Changes

- 데스크톱: 위저드 패널 하단에 취소/이전/다음 또는 VM 생성 네비게이션을 고정한다.
- 모바일: 네비게이션을 패널 상단에 고정하고 이전/취소/다음 순서로 배치한다.
- 긴 이미지 목록과 설정 단계가 네비게이션을 가리지 않도록 불투명 배경과 안전 영역 여백을 유지한다.
- 기존 튜토리얼용 `data-tour` 앵커와 버튼 동작은 하나의 네비게이션 인스턴스로 유지한다.

## Out of Scope

- VM 생성 단계 자체, API 요청 형식, 유효성 검증 변경
- 다른 `SlidePanel` 소비자의 레이아웃 변경
