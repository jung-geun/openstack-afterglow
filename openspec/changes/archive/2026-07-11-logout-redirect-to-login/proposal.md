# 로그아웃 로그인 페이지 리다이렉트

## Goal

명시적인 로그아웃 또는 현재 세션 폐기 뒤에는 공개 랜딩(`/`)이 아니라 로그인 페이지(`/login`)로 이동한다.

## Scope

- 전역 헤더와 프로젝트 선택 화면의 로그아웃 이동 대상을 `/login`으로 통일한다.
- 보안 설정에서 마지막 세션 삭제 또는 전체 로그아웃으로 인증이 해제되는 경로도 `/login`으로 통일한다.
- 히스토리를 대체해 뒤로 가기로 인증된 화면을 다시 열지 않도록 한다.
- 모든 경로를 고정하는 프론트엔드 회귀 테스트를 추가·갱신한다.

## Non-goals

- 서버 로그아웃 API 또는 인증 저장소의 동작을 변경하지 않는다.
- 로그인 완료 토스트·확인 대화상자 UX를 변경하지 않는다.
