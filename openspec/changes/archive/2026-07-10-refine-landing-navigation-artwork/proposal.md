# refine-landing-navigation-artwork

## Goal
Afterglow 루트 랜딩 페이지를 사용자가 요청한 여섯 가지 방향으로 다듬어, 상태 정보에 의존하지 않고 제품의 컴퓨팅·Kubernetes·운영 가치를 즉시 이해할 수 있는 탐색·시각 언어와 실제 문의 동선을 제공한다.

## Scope
- 루트 랜딩에서 VOL/status/GitHub 상태 스트립을 전체 제거하고, 스트립에만 필요했던 GitHub 요청 상태·타이머·클라이언트 로직과 CSP `connect-src` 허용도 함께 제거한다.
- 섹션 내비게이션을 화면 위에 지속적으로 남는 오버레이로 바꾸고, 현재 스크롤한 섹션을 활성 상태로 강조하여 개요·기능·워크플로우·화면·문의 위치를 명확히 전달한다.
- VM/GPU와 Kubernetes를 단순 장식으로 보이지 않도록 이해 가능한 비주얼과 설명 카피로 정리해, 컴퓨팅 자원·GPU 활용·클러스터 운영의 관계를 빠르게 파악할 수 있게 한다.
- 깨졌거나 의미를 전달하지 못하는 관측 가능성(Observability) artwork를 제거하고, 별도 이미지 파일 없이 기존 아이콘·도형·타이포그래피로 구성한 아이콘 중심 비주얼로 교체한다.
- 실제 목적지나 행동이 없는 푸터 열(footer columns)을 제거하고, 유효한 브랜드·저작권·문의/저장소 링크만 남겨 푸터의 정보 구조를 단순화한다.
- 문의 CTA를 외부 폼이나 가짜 동작이 아닌 `mailto:pieroot@konkuk.ac.kr` 기반으로 연결하고, 버튼·링크의 접근 가능한 이름과 기본 동작을 유지한다.
- 위 변경에 대한 랜딩 컴포넌트·라우트/CSP 회귀 검증과 데스크톱·모바일 브라우저 검증을 위한 집중 테스트 범위를 정의하고, 결과를 기록한 뒤 OpenSpec 변경을 보관한다.
