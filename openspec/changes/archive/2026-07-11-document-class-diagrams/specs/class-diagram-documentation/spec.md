## ADDED Requirements

### Requirement: 운영 타입 클래스 다이어그램 문서

시스템은 운영 코드의 이름 있는 타입을 원본 경로 구조로 미러링한 Mermaid 클래스 다이어그램 문서로 제공해야 한다. 시스템은 각 문서에서 주요 멤버와 정적 관계 근거를 MUST 제공한다.

#### Scenario: 다이어그램 인덱스에서 경로 문서 탐색

- **WHEN** 유지보수자가 클래스 다이어그램 인덱스를 연다
- **THEN** backend 및 frontend 운영 경로별 다이어그램 문서로 이동할 수 있다
- **AND** 각 문서는 타입, 주요 멤버, 정적 관계 근거를 표시한다
