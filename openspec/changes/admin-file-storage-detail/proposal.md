# admin-file-storage-detail

## Goal
관리자 파일스토리지 목록에서 상세/내부 데이터 확인과 파일스토리지 삭제를 수행할 수 있게 한다.

## Scope
- 관리자 파일스토리지 목록에서 항목 상세 패널을 열 수 있게 한다.
- 기존 `/api/v1/file-storage/{id}` 상세, access-rules 조회, 삭제 엔드포인트를 재사용한다.
- 삭제 성공 후 관리자/프로젝트 파일스토리지 목록 캐시를 무효화한다.
- 관리자 상세 패널은 접근 규칙을 읽기 전용으로만 표시한다.

## Non-goals
- 새 관리자 삭제 엔드포인트 추가.
- 접근 규칙 추가/삭제 UI 제공.
- 일반 사용자 파일스토리지 상세 패널 변경.
