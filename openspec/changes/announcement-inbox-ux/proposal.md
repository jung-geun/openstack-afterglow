# 공지/알림 UX 개선 (announcement-inbox-ux)

## 목표

2026-07-12 도입된 관리자 공지 시스템(`2026-07-12-admin-user-announcements`)의 사용자 접점 3곳을 개선한다.

1. **대시보드 "시스템 알림" 카드** — 공지 제목 클릭 시 알림함의 해당 공지로 바로 이동(전체보기 링크만으로는 접근 동선이 김).
2. **헤더 종(bell) 아이콘** — 클릭 시 드롭다운으로 최근 공지 목록을 즉시 표시하고, "전체 알림 보기"로 알림함 이동.
3. **알림함 상세 보기** — 각 공지를 펼쳐 본문 전문과 메타데이터(발송자 이름·유저 ID, 발송/게시 시각, 만료 시각)를 확인 가능하게.

## 배경

사용자 피드백(2026-07-13, 스크린샷 3장): 대시보드 카드의 공지가 클릭 불가, 종 아이콘이 단순 링크, 알림함에 발송자/만료 정보 부재.

## 범위

- **백엔드**: 사용자용 공지 응답(`_serialize_user` / `AnnouncementUserResponse`)에 `created_by_username`, `created_by_user_id`, `starts_at`, `ends_at` 필드 추가(하위호환 — 필드 추가만).
- **프론트엔드**: `types/announcements.ts` 확장, `dashboard/+page.svelte` 제목 링크화, `+layout.svelte` 종 드롭다운, `dashboard/notifications/+page.svelte` 펼침 상세 + `?focus=` 딥링크.
- **테스트**: 사용자 페이로드 필드 계약 테스트 추가, 기존 프론트 테스트 갱신.

## 비범위 (기존 결정 유지)

- 그룹 타겟팅, SSE 실시간 푸시, DB-less 공지 폴백 — 후속 과제 그대로.
- 읽음 처리 시점 변경(알림함 진입 시 일괄 읽음 처리 유지).
